# Lifting Status

Breakdown of function lifting results for each binary for which lifting was attempted.
The columns show the following per binary:
- **Source files:** the number of source files for which functions were analyzed.
- **Analyzed:** the number of functions analyzed. In most cases these are all the
  functions present in the source files considered.
- **Lifted:** the number of functions that were successfully lifted. A function is
  considered successfully lifted if: (1) no diagnostics were generated during
  lifting, (2) all local variables are typed, (3) the function is parsed
  (syntactically) by gcc without errors, and (4) semantics were confirmed via
  manual inspection.
- **Errors:** the number of functions for which lifting produced one or more
  diagnostics (see [ERRORS](ERRORS.md)).
- **Typing:** the number of functions that lifted without errors, but that include
  one or more local variables without type.
- **Other Issues:** the number of functions for which gcc parsing failed or that have
  semantic issues identified by manual inspection.

The table is generated by `./make_status.py --top` from the `vars.sh` files of the
lifting directories.
